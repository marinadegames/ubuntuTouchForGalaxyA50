## Сборка

Из корня репозитория, с установленным Python 3.9+ и запущенным Docker Linux ARM64:

```sh
./build.sh --version 0.0.1
```

## Установка через TWRP

1. Убедись, что телефон — **SM-A505F**, загрузчик разблокирован, установлены
   совместимая база **Android 11** и рабочий **TWRP**.
2. В TWRP выбери **Wipe → Format Data**, введи `yes`, затем **Reboot → Recovery**.
   **Внутренняя память будет полностью очищена.**
3. В **Mount** смонтируй **Data**. Скопируй с компьютера файл
   **`release/ubuntu-touch-a50-0.0.1.zip`** на телефон или microSD. ZIP не распаковывай.
4. Нажми **Install**, выбери **`ubuntu-touch-a50-0.0.1.zip`**.
   **Zip signature verification** оставь выключенным — ZIP не подписан.
5. Подтверди **Swipe to confirm Flash** и дождись **Installation verified** без ошибок.
   При ошибке остановись и оставайся в TWRP.
6. Нажми **Reboot System**, дождись первого запуска и пройди настройку Ubuntu Touch.
