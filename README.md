## Установка

Для установки нужен готовый образ **`ubuntu-touch-a50-2026-10-30-public-test.zip`**.
Сейчас он лежит в папке `release/` на компьютере. Для скачивания с GitHub этот
файл нужно отдельно прикрепить к **Releases**.

**Code → Download ZIP** скачивает исходники репозитория — этот архив прошивать нельзя.

Нужны разблокированный загрузчик, совместимый TWRP и базовая прошивка Android 11.
**Format Data полностью удалит данные телефона — заранее сохрани нужное.**

1. Найди `release/ubuntu-touch-a50-2026-10-30-public-test.zip`. **Не распаковывай его.**
2. В TWRP выбери **Wipe → Format Data**, затем **Reboot → Recovery**.
3. В **Mount** смонтируй **Data** и скопируй указанный ZIP с компьютера на телефон
   или карту microSD.
4. В **Install** выбери `ubuntu-touch-a50-2026-10-30-public-test.zip` и подтверди
   установку ползунком **Swipe to confirm**.
5. Нажми **Reboot System**, дождись загрузки и пройди первоначальную настройку.

> Сборка тестовая: чистая установка ещё не проверена. Пересборка после удаления
> VPN и захвата экрана отложена; ZIP в `release/` пока предыдущей версии.
